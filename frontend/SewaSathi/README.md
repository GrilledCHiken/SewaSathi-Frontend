# Sewa Sathi — Frontend

React 19 + Vite + Tailwind CSS frontend for Sewa Sathi. See the [root README](../../README.md)
for the full project overview.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

`VITE_API_BASE_URL` in `.env` should point at the backend API (defaults to
`http://localhost:8080/api`).

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
